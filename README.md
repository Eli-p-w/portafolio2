# Eliana Valencia — sitio web personal

Sitio web estático, adaptable a móviles y listo para desplegar en un hosting estático.

## Estructura

- `index.html`: contenido y estructura de la página.
- `styles.css`: diseño visual, colores y estilos responsive.
- `script.js`: menú móvil, animaciones de entrada y año automático.
- `assets/eliana-valencia.jpg`: fotografía suministrada.

## Ver localmente

Abre `index.html` en un navegador. Para una experiencia más cercana a producción, puedes servir la carpeta con cualquier servidor estático local.

## Publicar

Puedes desplegar toda la carpeta en Netlify, Vercel (como sitio estático), GitHub Pages o en el hosting de tu dominio. Mantén la estructura de carpetas para que las rutas de CSS, JavaScript e imagen funcionen.

## Personalización antes de publicar

1. Confirma si deseas mantener el nivel académico “Octavo semestre” o actualizarlo.
2. Añade teléfono, LinkedIn, Instagram profesional o enlace a portafolio si quieres mostrarlos. No se añadieron datos que no aparecen en la hoja de vida.
3. Reemplaza la fotografía en `assets/eliana-valencia.jpg` si deseas usar una versión de mayor resolución.
4. Si publicas en un dominio propio, añade los metadatos sociales (Open Graph) con la URL definitiva y una imagen de vista previa.

## Tecnologías

HTML5, CSS3 y JavaScript vanilla. No requiere instalación de dependencias ni proceso de compilación.
